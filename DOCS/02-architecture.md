## جریان داده (Data Flow)

```
           ┌─────────────────────────────────────────────────────────────┐
           │                         USER CODE                           │
           └─────────────────────────────┬───────────────────────────────┘
                                         │
                                         ▼
┌──────────────────────────────────────────────────────────────────────────┐
│ shapes.draw(signals)                                                      │
│                                                                           │
│ ورودی: APISignal[]                                                        │
│ [                                                                         │
│   {                                                                       │
│     signal_id: "abc123",                                                  │
│     strategy_id: 315,                                                     │
│     signal_type: "S",                                                     │
│     payload: { p1p: "100", p1t: 1234567, p2p: "95", p2t: 1234600, ... }  │
│   }                                                                       │
│ ]                                                                         │
└──────────────────────────────────────┬───────────────────────────────────┘
                                       │
                                       ▼
┌──────────────────────────────────────────────────────────────────────────┐
│ ShapeManager.draw()                                                       │
│                                                                           │
│ 1. بررسی آماده بودن renderer                                              │
│ 2. ارسال سیگنال‌ها به parser                                              │
└──────────────────────────────────────┬───────────────────────────────────┘
                                       │
                                       ▼
┌──────────────────────────────────────────────────────────────────────────┐
│ SignalParser.parseAll()                                                   │
│                                                                           │
│ برای هر سیگنال:                                                           │
│ 1. پیدا کردن StrategyConfig بر اساس strategy_id                           │
│ 2. ساخت Strategy مناسب (مثلاً TrendLineStrategy)                          │
│ 3. صدا زدن strategy.parse(signal, config)                                 │
│ 4. اضافه کردن entry marker (اختیاری)                                      │
└──────────────────────────────────────┬───────────────────────────────────┘
                                       │
                                       ▼
┌──────────────────────────────────────────────────────────────────────────┐
│ Strategy.parse()                                                          │
│                                                                           │
│ 1. استخراج نقاط از payload (p1p, p1t, p2p, p2t, ...)                     │
│ 2. اعتبارسنجی تعداد نقاط                                                  │
│ 3. تبدیل زمان به میلی‌ثانیه                                               │
│ 4. ساخت overrides (رنگ، ضخامت، استایل)                                   │
│ 5. برگرداندن ShapeResult                                                  │
└──────────────────────────────────────┬───────────────────────────────────┘
                                       │
                                       ▼
┌──────────────────────────────────────────────────────────────────────────┐
│ خروجی: ShapeResult[]                                                      │
│ [                                                                         │
│   {                                                                       │
│     type: "trend_line",                                                   │
│     points: [{ time: 1234567000, price: 100 }, { time: 1234600000, ... }]│
│     overrides: { linecolor: "#f44336", linewidth: 2 },                   │
│     signalId: "abc123"                                                    │
│   }                                                                       │
│ ]                                                                         │
└──────────────────────────────────────┬───────────────────────────────────┘
                                       │
                                       ▼
┌──────────────────────────────────────────────────────────────────────────┐
│ ShapeRenderer.drawAll()                                                   │
│                                                                           │
│ برای هر ShapeResult:                                                      │
│ 1. تبدیل نقاط به فرمت TradingView (ثانیه)                                 │
│ 2. ساخت shapeOptions                                                      │
│ 3. صدا زدن chart.createMultipointShape() یا chart.createShape()          │
│ 4. ذخیره reference برای حذف بعدی                                          │
└──────────────────────────────────────┬───────────────────────────────────┘
                                       │
                                       ▼
┌──────────────────────────────────────────────────────────────────────────┐
│ TradingView Chart API                                                     │
│                                                                           │
│ chart.createMultipointShape(                                              │
│   [{ time: 1234567, price: 100 }, { time: 1234600, price: 95 }],         │
│   {                                                                       │
│     shape: "trend_line",                                                  │
│     lock: false,                                                          │
│     disableSelection: true,                                               │
│     overrides: { linecolor: "#f44336", linewidth: 2 }                    │
│   }                                                                       │
│ )                                                                         │
│                                                                           │
│ خروجی: shapeId (یک identifier برای شکل ساخته شده)                        │
└──────────────────────────────────────────────────────────────────────────┘
```

## لایه‌بندی وابستگی‌ها

```
┌────────────────────────────────────────────┐
│              Application Layer              │
│                                             │
│   React App / WebView / Any JS App         │
│                                             │
└─────────────────────┬───────────────────────┘
                      │ استفاده می‌کند از
                      ▼
┌────────────────────────────────────────────┐
│              Public API Layer               │
│                                             │
│   NXCChartShapes (ShapeManager)            │
│   - attach()                                │
│   - draw()                                  │
│   - clear()                                 │
│   - registerStrategy()                      │
│                                             │
└─────────────────────┬───────────────────────┘
                      │ وابسته است به
                      ▼
┌────────────────────────────────────────────┐
│               Core Layer                    │
│                                             │
│   SignalParser, ShapeRenderer              │
│                                             │
└─────────────────────┬───────────────────────┘
                      │ استفاده می‌کند از
                      ▼
┌────────────────────────────────────────────┐
│             Strategy Layer                  │
│                                             │
│   BaseStrategy, TrendLineStrategy, ...     │
│                                             │
└─────────────────────┬───────────────────────┘
                      │ استفاده می‌کند از
                      ▼
┌────────────────────────────────────────────┐
│             Utility Layer                   │
│                                             │
│   colors, points, time utilities           │
│                                             │
└─────────────────────┬───────────────────────┘
                      │ وابسته است به
                      ▼
┌────────────────────────────────────────────┐
│              Types Layer                    │
│                                             │
│   APISignal, ShapeResult, StrategyConfig   │
│   (هیچ وابستگی runtime ندارد)              │
│                                             │
└────────────────────────────────────────────┘
```

## فایل‌های هر لایه

```
src/
├── index.ts                 # Public API exports
│
├── core/                    # Core Layer
│   ├── ShapeManager.ts      # مدیر اصلی
│   ├── SignalParser.ts      # تجزیه‌گر سیگنال
│   ├── ShapeRenderer.ts     # رندر شکل
│   └── WidgetFactory.ts     # ساخت widget (اختیاری)
│
├── strategies/              # Strategy Layer
│   ├── BaseStrategy.ts      # کلاس پایه
│   ├── TrendLineStrategy.ts # خط روند
│   ├── ChannelStrategy.ts   # کانال
│   ├── PatternStrategy.ts   # الگوها
│   ├── FibonacciStrategy.ts # فیبوناچی
│   ├── ZoneStrategy.ts      # زون/مستطیل
│   ├── EntryPointStrategy.ts# نشانگر ورود
│   └── index.ts             # صادرات
│
├── utils/                   # Utility Layer
│   ├── colors.ts            # رنگ‌ها
│   ├── points.ts            # نقاط
│   ├── time.ts              # زمان
│   └── index.ts             # صادرات
│
└── types/                   # Types Layer
    ├── signal.ts            # انواع سیگنال
    ├── shape.ts             # انواع شکل
    ├── strategy.ts          # انواع استراتژی
    ├── tradingview.ts       # انواع TradingView
    └── index.ts             # صادرات
```
